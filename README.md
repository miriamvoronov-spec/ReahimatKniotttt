# רשימרקט – הסופר שלך בכיס 🛒

אפליקציית אנדרואיד לרשימת קניות, בנויה לפי [SPEC.md](SPEC.md). הקובץ [demo.html](demo.html) הוא דמו של העיצוב וההתנהגות.

## איך מורידים את האפליקציה

הדרך הקלה: פותחים בטלפון את הקישור הזה, והקובץ יורד ישירות:
**https://github.com/miriamvoronov-spec/ReahimatKniotttt/releases/latest/download/reshimarket.apk**

הקישור תמיד מצביע על הגרסה האחרונה שנבנתה מ-main.

דרך נוספת, דרך GitHub Actions:

1. נכנסים ללשונית **Actions** במאגר הזה ב-GitHub.
2. בוחרים את הריצה האחרונה של **Build APK** שמסומנת בווי ירוק.
3. בתחתית העמוד, תחת **Artifacts**, לוחצים על **reshimarket-apk**. יורד קובץ ZIP.
4. פותחים את ה-ZIP. בפנים יש קובץ בשם `reshimarket.apk`.

## איך מתקינים בטלפון

1. מעבירים את `reshimarket.apk` לטלפון (או מורידים את ה-ZIP ישירות מהטלפון ופותחים אותו).
2. לוחצים על הקובץ. בפעם הראשונה אנדרואיד יבקש לאשר "התקנה ממקורות לא ידועים" לאפליקציה שממנה פתחת את הקובץ (למשל Chrome או "הקבצים שלי"). מאשרים וחוזרים.
3. לוחצים **התקנה**. אם Google Play Protect מציג אזהרה, בוחרים "פרטים נוספים" ואז "להתקין בכל זאת".

כל APK חדש חתום באותו מפתח, אז אפשר להתקין גרסה חדשה מעל הקודמת והרשימות נשמרות.

## ווידג'ט

לחיצה ארוכה על מסך הבית ← ווידג'טים ← רשימרקט. הווידג'ט מראה כמה מוצרים חסרים ברשימה הפעילה.

## טכנולוגיה

Kotlin, Jetpack Compose, Material 3, MVVM, Room, Jetpack Glance. minSdk 26.
שכבת הנתונים עוברת דרך `ShoppingRepository`, כך שאפשר להוסיף בעתיד סנכרון בענן (Firebase) בלי לשכתב את המסכים.
